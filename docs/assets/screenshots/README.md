# README 截图位

中英文 README 固定引用以下三个文件：

- `chat-workspace.webp`：桌面端对话工作台主图；
- `file-and-tools.webp`：文件、提取与工具运行；
- `admin-settings.webp`：管理后台配置。

把图片按以上文件名放入本目录后，中英文 README 会自动显示。建议使用 `1600×900` 或相同比例的 WebP：

1. 只使用虚构账号、虚构对话与脱敏地址；
2. 不包含真实用户、生产数据、密钥或内部主机信息；
3. 桌面主图保持完整工作台，另外两张分别聚焦文件/工具和管理治理，避免三张图重复表达同一内容。
